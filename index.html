Quatro valores base alimentam todo o EVM. Deles derivam variações, índices e projeções.

Valores base

BACBudget at Completion
Orçamento total aprovado.
BAC = linha de base
  • Não muda sem CR formal.
PVPlanned Value
Quanto deveria estar gasto até hoje.
PV = BAC × % planejado
EVEarned Value
Valor do trabalho efetivamente entregue.
EV = BAC × % executado
  • Núcleo do EVM: progresso em R$.
ACActual Cost
Quanto foi realmente gasto.
AC = custos incorridos

Variações

CVCost Variance
CV = EV − AC
  • Positivo = abaixo do orçamento · Negativo = estourando
SVSchedule Variance
SV = EV − PV
  • Positivo = adiantado · Negativo = atrasado

Índices de performance

CPICost Performance Index
CPI = EV / AC
  • ≥ 0,95 Verde · 0,85–0,95 Amarelo · < 0,85 Vermelho
SPISchedule Performance Index
SPI = EV / PV
  • ≥ 0,95 Verde · 0,85–0,95 Amarelo · < 0,85 Vermelho

Projeções

EACEstimate at Completion
EAC = BAC / CPI
  • Se EAC > BAC → estouro esperado.
VACVariance at Completion
VAC = BAC − EAC
  • Positivo = economia · Negativo = estouro

Matriz de Riscos P×I

Padrão PMI/PMBOK. Probabilidade (P) × Impacto (I) = Score de exposição.
Score ≥ 15 = Alto (vermelho) · 6–14 = Médio (amarelo) · 1–5 = Baixo (verde).
Cada risco aparece como chip na célula correspondente à sua P e I.
