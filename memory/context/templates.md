```
|----|-------|-----------|---------|---------|-------|------------|----------|-------------|------|
```

## Entrada no log de decisões

```
- **YYYY-MM-DD** — [Decisão tomada]. Decisor: [nome]. Contexto: [...]. Impacto: [...].
```

## Mudança de escopo (change request curto)

```
**CR-NNN — [Título]**
- Solicitante: ...
- Data: YYYY-MM-DD
- Mudança: o que está sendo alterado
- Justificativa: por quê
- Impacto: cronograma (+N dias), custo (+R$ X), escopo
- Aprovação: pendente / aprovada / rejeitada (data, decisor)
```
