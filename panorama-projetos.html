Como interpretar os indicadores

Quatro valores base alimentam todo o EVM. A partir deles derivam as variações, os índices de performance e as projeções para o fim do projeto.

Valores base — todos em R$

BACBudget at Completion
Orçamento total aprovado para o projeto.
BAC = soma da linha de base
  • É o "alvo" original — não muda sem mudança formal de escopo (CR).
PVPlanned Value · Valor Planejado
Quanto eu deveria ter gasto até hoje, conforme o cronograma.
PV = BAC × % planejado
  • Representa a curva esperada de consumo do orçamento ao longo do tempo.
EVEarned Value · Valor Agregado
Valor que já foi "ganho" — corresponde ao trabalho efetivamente entregue.
EV = BAC × % executado
  • É o conceito-chave do EVM: traduz progresso em R$.
ACActual Cost · Custo Real
Quanto eu realmente gastei até a data.
AC = soma dos custos incorridos
  • Vem direto do financeiro / razão contábil.

Variações — em R$

CVCost Variance · Variação de Custo
Diferença entre o valor entregue e o que foi gasto.
CV = EV − AC
  • Positivo — entregou mais valor do que gastou
  • Zero — gastou exatamente o que deveria
  • Negativo — está estourando o orçamento
SVSchedule Variance · Variação de Cronograma
Diferença entre o valor entregue e o que era esperado entregar.
SV = EV − PV
  • Positivo — adiantado em relação à baseline
  • Zero — exatamente no plano
  • Negativo — atrasado

Índices de performance — sem unidade

CPICost Performance Index
Eficiência de custo: quanto valor o projeto entrega por R$ gasto.
CPI = EV / AC
  • ≥ 1,00 — eficiência boa (cada R$ gasto rende ≥ R$ 1)
  • 0,95–1,00 — saudável
  • 0,85–0,95 — atenção (amarelo)
  • < 0,85 — crítico (vermelho)
SPISchedule Performance Index
Eficiência de cronograma: quanto do trabalho planejado está concluído.
SPI = EV / PV
  • ≥ 1,00 — no prazo ou adiantado
  • 0,95–1,00 — saudável
  • 0,85–0,95 — atenção (amarelo)
  • < 0,85 — crítico (vermelho)

Projeções para o fim do projeto

EACEstimate at Completion
Quanto o projeto vai custar no total, mantida a eficiência atual.
EAC = BAC / CPI
  • Se EAC > BAC, o projeto deve estourar; se <, tende a economizar.
ETCEstimate to Complete
Quanto ainda falta gastar até o fim do projeto.
ETC = EAC − AC
  • Útil para reservar orçamento residual ou pedir suplementação.
VACVariance at Completion
Estouro ou economia previsto no final do projeto.
VAC = BAC − EAC
  • Positivo — economia esperada · Negativo — estouro esperado

Classificação RAG

🟢 Verde CPI ≥ 0,95 e SPI ≥ 0,95 e sem risco aberto de severidade alta.
🟡 Amarelo Um dos índices entre 0,85 e 0,95, ou risco alto aberto sem plano de resposta.
🔴 Vermelho CPI < 0,85 ou SPI < 0,85 ou estouro confirmado de prazo / orçamento.
